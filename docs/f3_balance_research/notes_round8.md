# F₃ 第八轮：临界层的精确斜线结构、计数公式与近边界预筛

日期：2026-09-28。

## 0. 状态、对象与本轮增量

本文给出自含的纸面推导，另附精确整数/有理数核验代码。没有新增 Lean 证明，没有修改 GitHub，没有证明新的孪生素数存在性下界，也没有完成具体结果的系统优先权检索。

本轮只研究**两个因子都在 (1,m) 内的奇数逆元配对**，m=3^r。它是前几轮半素数因子区域的平衡部分，不能覆盖允许 b>m 的全部原始污染项。

第七轮已经证明：若 1<a,b<m 均为奇数且 ab≡1 (mod m)，则 F₃(a)=F₃(b)=±j，并且 2j<r。也已给出预筛层分布在 j 与 r/2 保持固定比例距离时的主项。本轮不把这些继承结果重新称为新发现。

新增的核心是：

1. 在 r=2j+c、1≤c≤j，即 r/3≤j<r/2 的范围，给出全部数对的**精确算术数列参数化**；固定 c 时，它们在缩放后只落在有限条斜线上。
2. 完整正方形的每个符号层计数有闭式；特定盒中 +j 与 −j 的不对称能持续到任意大的尺度，不是有限样本噪声。
3. 在这个范围，平方自由筛模数 d 的计数误差改善为 O((3^j+3^c)4^ω(d))，无需使用 Kloosterman 界。可用筛模数规模由此前通用方法约 3^(c/3) 改为约 3^c，保留严格余量。
4. 在相同预筛门槛 y=exp(√log m) 下，将预筛主项推进到 c/(√r log r)→∞，不再要求固定比例的深度余量。它仍然是预筛主项，不是三素数主项。
5. 固定 c 的临界带里，小素数局部因子依赖所在斜线；固定有限筛素数集合时会出现关于 j 的周期密度。不能把浅层二维平均密度逐条移植到临界斜线。

以下所有计数均为**有序对** (a,b)。若另加 a<b，须单独处理；这里不默默除以 2。

## 1. 定义和符号

对整数 n>1：

\[
F_3(n)=v_3(n+1)-v_3(n-1).
\]

取

\[
r=2j+c,\qquad 1\le c\le j,\qquad
 t=3^j,\quad s=3^c,\quad m=t^2s=3^r.
\]

用 ε∈{−1,+1} 标记 n≡ε (mod3) 的分支。因此这里

\[
F_3(a)=F_3(b)=-\epsilon j.
\]

尤其 ε=−1 对应正层，ε=+1 对应负层，不要把 ε 与 F₃ 的符号混用。

令 R=(α,β]×(γ,δ]⊂[0,1]^2 为固定矩形，面积

\[
\mathcal A=(\beta-\alpha)(\delta-\gamma)>0.
\]

计数时还要求 1<a,b<m，取整只影响端点上的有界误差。定义斜线 x+y=z 在盒中投影到 x 轴的长度

\[
\ell_R(z)=\big[\min(\beta,z-\gamma)-\max(\alpha,z-\delta)\big]_+.
\]

它是连续分段线性函数，支撑在 [0,2]，总变差至多 2，而且

\[
\int_{\mathbb R}\ell_R(z)\,dz=\mathcal A.
\]

## 2. 二次逆元的精确正规形

### 定理 A

在第 1 节参数范围内，满足

\[
1<a,b<m,\quad a,b\text{ 奇},\quad ab\equiv1\pmod m,
\quad F_3(a)=F_3(b)=-\epsilon j
\]

的有序对，与以下参数一一对应：

\[
a=\epsilon+2tu,\qquad b=\epsilon+2tv,
\]

\[
1\le u,v\le U:=\frac{ts-1}{2},\quad
u+v=th,\quad 1\le h<s,
\]

准确的同余条件为

\[
\boxed{u+v=th,\qquad 2u^2\equiv\epsilon h\pmod s,\qquad 3\nmid u.}
\tag{2.1}
\]

可行的 h 恰满足

\[
\boxed{h\equiv-\epsilon\pmod3.}
\tag{2.2}
\]

每个这样的 h，(2.1) 对 u 模 s 恰有两个根。

### 证明

同层及奇数条件允许唯一写成 a=ε+2tu、b=ε+2tv，3∤uv，且上界给出 U。

由于 ab−1 为偶数、m 为奇数，ab≡1 (mod m) 等价于 ab≡1 (mod2m)。展开并除以 2t：

\[
\epsilon(u+v)+2tuv\equiv0\pmod{ts}.
\]

先模 t，得到 u+v=th。u,v>0 且 u+v≤ts−1，故 1≤h<s。再除以 t：

\[
\epsilon h+2uv\equiv0\pmod s.
\]

这里 c≤j，所以 s|t；代入 v=th−u，得到 2u²≡εh (mod s)。

模 3 下 u²≡1，故 h≡−ε (mod3)。反过来，若 h 满足这一条件，则 εh/2 是模 3 的平方单位；两个模 3 的根均为单位，导数 2u 不被 3 整除，逐层提升各有唯一选择。因此模 3^c 恰有两个根。

逆向代入原式即可证明充分性，也保证 v≡−u (mod3)，所以两端深度都恰为 j。

### 实际可计算的形式

遍历模 s 的单位 u₀，令

\[
h\equiv2\epsilon u_0^2\pmod s,\qquad1\le h<s.
\]

所有对应点为

\[
\boxed{
\begin{aligned}
a&=\epsilon+2tu_0+2ts\,l,\\
b&=\epsilon+2t(th-u_0)-2ts\,l,
\end{aligned}
\qquad l\in\mathbb Z,
}
\tag{2.3}
\]

只需用矩形边界截取 l 的一个整数区间。不同 u₀ 给出的点互不重复。

这是有限逆元展开在当前深度的具体化，不是声称发现新的 p-adic 逆元算法。

## 3. 临界层不是二维均匀点云

由正规形立刻有

\[
\boxed{a+b=2\epsilon+2t^2h.}
\tag{3.1}
\]

缩放 x=a/m、y=b/m：

\[
\boxed{x+y=\frac{2h}{s}+\frac{2\epsilon}{m},\qquad
1\le h<s,\ h\equiv-\epsilon\pmod3.}
\tag{3.2}
\]

固定 c 时共有 s/3 条斜线；每条斜线由两个步长 2ts 的算术数列组成。缩放后，每支在 x 方向的步长为 2/t。

### 定理 B（临界层盒计数）

记 N_(j,c,ε)(R) 为本层在 R 中的点数。则

\[
\boxed{
N_{j,c,\epsilon}(R)
=t\sum_{\substack{1\le h<s\\h\equiv-\epsilon\ (3)}}
\ell_R(2h/s)+O(s),
}
\tag{3.3}
\]

隐常数可取绝对常数。

证明：每根模 s 的分支在 x 上每隔 2/t 取一点，因此在长度 ℓ 的线段上计数为 (t/2)ℓ+O(1)。两个根相加。实际斜线相对 2h/s 平移 2ε/m，长度改变量至多 2/m；其总计数影响 O(ts/m)=O(1/t)。端点处理同样被 O(s) 吸收。

于是固定 c、j→∞ 时，N/t 的极限是有限条斜线的弦长和，而非通常的面积常数。

更完整地，对于 [0,1]^2 上连续函数 f，经验测度 (1/t)Σδ_(a/m,b/m) 收敛到

\[
\sum_{\substack{1\le h<s\\h\equiv-\epsilon\ (3)}}
\int_{\max(0,2h/s-1)}^{\min(1,2h/s)}
f(x,2h/s-x)\,dx.
\]

这是非归一化测度，其总质量见下一节。

### 离开临界带后的普通均匀性

Riemann 和给出

\[
\sum_{h\equiv-\epsilon(3)}\ell_R(2h/s)
=\frac{s}{6}\mathcal A+O(1).
\]

故

\[
N_{j,c,\epsilon}(R)=\frac{ts}{6}\mathcal A+O(t+s).
\tag{3.4}
\]

当 t,s→∞ 且 s≤t 时，主项的相对误差 O_R(1/s+1/t) 趋零。因此对于**未筛整数点**，只要 c→∞ 即可恢复盒中的面积主项，不必要求 c/r 有固定正下界。固定 c 则一般不能恢复。

## 4. 完整正方形的闭式与一个永久单侧盒

### 定理 C（完整正方形每个符号层的精确计数）

对 1≤c≤j，两个符号各自的有序对数都恰等于

\[
\boxed{
\frac{ts}{6}+\frac{t}{2s}
=\frac{3^{r-j}}6+\frac{3^{3j-r}}2.
}
\tag{4.1}
\]

没有渐近误差。右边虽然写了分母，但总和总是整数。

证明：固定 h。若 h<s/2，u∈[1,th−1]，且 t 是 s 的倍数；每个单位根恰出现 th/s 次，共 2th/s 点。若 h>s/2，u∈[th−U,U]，该区间含 t(s−h) 个整数，是 s 的整数倍，两个根共出现 2t(s−h)/s 次。

因此总数等于

\[
\frac{2t}{s}\sum_{\substack{1\le h<s\\h\equiv-\epsilon\ (3)}}
\min(h,s-h).
\]

对奇数 s=3^c，直接把和在 s/2 处分段可得

\[
\sum_{h\equiv-\epsilon(3)}\min(h,s-h)=\frac{s^2+3}{12}.
\]

两侧通过 h↦s−h 对称。代回即得。

与形式上的面积主项 ts/6 比较，精确比值为

\[
1+\frac3{s^2}=1+3^{1-2c}.
\]

这是每个符号层相对其面积主项的校正，不是相对于全部素数的概率。

### 定理 D（上一轮盒中的永久符号缺失）

固定

\[
R=(1/4,1/3]\times(1/2,2/3],\qquad c=2,\quad j\ge2.
\]

那么

\[
\boxed{
N_{+j}(R)=
\begin{cases}(3^j+3)/12,&j\text{ 为偶数},\\
(3^j+9)/12,&j\text{ 为奇数},\end{cases}
\qquad N_{-j}(R)=0.
}
\tag{4.2}
\]

这里 N_(±j) 用 F₃ 的符号，而不是 ε。

证明：s=9。正层 ε=−1 的线为 x+y=2/9、8/9、14/9 再减 2/m；负层 ε=+1 的线为 4/9、10/9、16/9 再加 2/m。盒内 x+y∈(3/4,1]。只有正层 h=4 的线穿过盒，而且其 x 投影完整覆盖 (1/4,1/3]（m≥729）。

该线的根为 u≡4,5 (mod9)。直接计数

\[
m/4<-1+2tu\le m/3
\]

中的这两个剩余类，并用 3^j 模 72 的周期，得到 (4.2)。

本轮独立核对第七轮的原始 CSV：r=16、j=7 的正层原始点有183个，负层0个；正层中通过≤66素因子预筛的点有16个。新公式解释的是183→16的来源及负层永久为0，不把16个预筛点说成16个三素数点。

## 5. 临界斜线上的局部筛因子

一条线的整数和固定为

\[
C_h=2\epsilon+2t^2h,\qquad b=C_h-a.
\]

对素数 p≥5，定义

\[
\rho_p(C)=\#\{a\bmod p:p\mid a(C-a)(a(C-a)-2)\}.
\]

### 引理

\[
\boxed{
\rho_p(C)=3-\mathbf1_{p\mid C}+\left(\frac{C^2-8}{p}\right).
}
\tag{5.1}
\]

Legendre 符号在分子被 p 整除时取 0。

证明：a=0 或 a=C 有 2−1_(p|C) 个点；a(C−a)=2 的根数是 1+((C²−8)/p)，且与前两种点不交。相加即可。因此 0≤ρ_p(C)≤4<p，没有 p≥5 的单素数局部全覆盖障碍。

对于固定有限素数集合 P⊂{5,7,11,…}，令

\[
V_h(t;P)=\prod_{p\in P}(1-\rho_p(C_h)/p).
\]

固定 c,P 时，预筛计数满足

\[
N^{P}_{j,c,\epsilon}(R)
=t\sum_{h\equiv-\epsilon(3)}\ell_R(2h/s)V_h(t;P)
+O_P(s).
\tag{5.2}
\]

证明：每条根分支参数 l 的系数 2ts 与所有 p∈P 互素，故逐模 p 的好参数数目为 p−ρ_p(C_h)；CRT 合并后在 l 的区间计数。误差每条分支至多常数倍 ∏p，固定 P 即得。

注意：这一局部因子一般不等于前几轮二维平均中的 1−3/p+2/p²。只有对 h 作完整剩余类平均，才恢复后者。

### 可证明的周期变化，不是拟合

在第 4 节的 c=2 单侧盒中，唯一斜线为 h=4、ε=−1：

\[
C_j=-2+8\cdot9^j.
\]

只筛 P={5,7,11}。V(C_j) 关于 j 的一个周期为30，因为9在模5、7、11的阶分别为2、3、5。计算得到

\[
\begin{aligned}
j\equiv12\pmod{30}:&\quad V=12/55,\\
j\equiv25\pmod{30}:&\quad V=216/385.
\end{aligned}
\]

由(5.2)，沿这两条无穷子序列，预筛幸存数与原始点数之比分别趋向上述两个不同的正常数。因此在固定临界宽度中，连固定有限素数预筛的密度都可以随尺度周期变化；不能宣称一个不依赖斜线、相位的统一常数。

本轮以整数 CRT 精确核验 j=30,…,59 的全部30个相位。例：j=42 的总点数9118249094292696601、预筛点数1989436166027497441；j=55 的对应计数分别为14537434250760014922597543、8156067008218605774756025。这是有限预筛计数，不是素数计数。

## 6. 更精细的平方自由模数分布

固定 R、ε，在本层中记 A_d 为另外满足

\[
d\mid ab(ab-2)
\]

的点数。d 平方自由、(d,6)=1。令

\[
g(d)=\prod_{p\mid d}\frac{3p-2}{p^2},\qquad
X_j=\frac{ts}{6}\mathcal A=\frac{m}{6\cdot3^j}\mathcal A.
\]

### 定理 E

\[
\boxed{
A_d=g(d)X_j+O\big((t+s)4^{\omega(d)}\big).
}
\tag{6.1}
\]

隐常数绝对；不需要 d 小于 m 才使等式成立（要让误差小于主项则当然需要限制 d）。没有素数指示函数被插入这个整数计数公式。

### 证明：分支计数、正的周期平均、分部求和

令

\[
\rho_h(d)=\prod_{p\mid d}\rho_p(C_h),\qquad
 g_h(d)=\rho_h(d)/d.
\]

每个 h 有两个 u 模 s 根，对应两个 l 算术数列。因为 2ts 与 d 互素，每支中 d|ab(ab−2) 恰对应 ρ_h(d) 个 l 模 d 类。因此两个分支相加后

\[
A_{d,h}=t\ell_R(C_h/m)g_h(d)+O(\rho_h(d)).
\tag{6.2}
\]

一个安全的显式误差倍数可以取每行8ρ_h(d)，涵盖所有开闭端点及1<a,b<m的边界。

由于 ρ_h(d)≤4^ω(d)，对 h 求和的局部误差是 O(s4^ω(d))。

现在按 h=h₀+3i 排列可行斜线。C_h 每次增加6t²，与d互素，所以 h 遍历d个相位时，C_h遍历所有模d类。完整平均严格满足

\[
\boxed{\frac1d\sum_{i\bmod d}g_{h_0+3i}(d)=g(d).}
\tag{6.3}
\]

这是模d上的二维点计数：在模p下，总坏点数为3p−2；CRT给出一般d。

所有 g_h(d) 非负。故任意不完整周期的中心化前缀和，绝对值至多 d g(d)，而

\[
dg(d)=\prod_{p\mid d}(3-2/p)\le3^{\omega(d)}.
\]

对有界变差权 ℓ_R(2h/s) 做离散分部求和，得到

\[
\sum_h\ell_R(2h/s)g_h(d)
=g(d)\frac{s}{6}\mathcal A+O(3^{\omega(d)}).
\]

平移2ε/m带来的长度改变对总计数只有O(1)。乘以t并加回局部误差即得(6.1)。例如采用保守边界预算可统一写成100(t+s)4^ω(d)；有限测试使用更小的20倍做排错，但不把测试最优值称为定理最优常数。

### 可用筛模数范围

若合成筛权大小不超过3^ω(d)，则

\[
\boxed{
\sum_{d\le D}^{*}3^{\omega(d)}|A_d-g(d)X_j|
\ll tD(1+\log D)^{11}.
}
\tag{6.4}
\]

因为s≤t，且12^ω(d)≤τ₁₂(d)，并可用基本除数卷积界 Σ_(d≤D)τ₁₂(d)≪D(1+logD)^11。

主项规模是ts。因此只要s→∞，对任意固定δ>0，D≤s^(1−δ)便有固定余量。与第七轮通用√(md)方法在同样深度给出的约s^(1/3)相比，这里利用二次正规形显著改善了模数损失。

严格限定：这只在c≤j的平衡盒中成立，不是把前几轮整个双曲区域的模数范围提高到m，也不是素数的分布定理。

## 7. 相同预筛门槛下，把主项推进到接近边界

令

\[
y=\exp(\sqrt{\log m}),\qquad
V(y)=\prod_{5\le p\le y}(1-3/p+2/p^2).
\]

仍只要求 a,b,ab−2 没有≤y的小素因子，不要求三者为素数。

### 定理 F（近边界预筛主项）

令r→∞，取j=j(r)、c=r−2j，满足

\[
1\le c\le j,
\qquad \frac{c}{\sqrt r\log r}\longrightarrow\infty.
\tag{7.1}
\]

则对每个固定正面积矩形R和任一ε=±1，

\[
\boxed{
N^{\mathrm{rough}}_{r,j,\epsilon}(R)
=(1+o(1))\frac{m\mathcal A}{6\cdot3^j}V(y).
}
\tag{7.2}
\]

这是第七轮相同门槛、相同主项在更近边界范围中的版本。例如

\[
j=\lfloor r/2-r^{2/3}\rfloor
\]

最终满足所有条件，且j/r→1/2。原先要求固定ε>0的j≤(1/2−ε)r并不覆盖这条序列。

### 证明

写L=logm、H=logs。条件(7.1)等价于 H/(√L logL)→∞。取

\[
k=\left\lfloor\frac{H}{8\sqrt L}\right\rfloor.
\]

则k/logL→∞。使用筛素因子个数的奇偶阶Bonferroni上下截断，截到2k+1和2k阶。所涉除数至多

\[
D=y^{2k+1},\qquad \log D\le H/4+\sqrt L\le H/3
\]

（最终成立）。把(6.1)的余项相加，有

\[
O\big(tD(1+\log D)^3\big),
\]

这里用4^ω(d)≤τ₄(d)，没有额外筛权。

另一方面，由Mertens乘积与局部恒等式1−g(p)=(1−1/p)(1−2/p)，有V(y)≍(logy)^−3=L^−3/2。相对主项tsV(y)，余项至多

\[
\ll (D/s)(1+\log D)^3L^{3/2}\to0,
\]

因为D≤s^(1/3)，且H≫√L logL。

主项截断的误差用U_y=Σ_(5≤p≤y)g(p)=O(logL)控制：第n阶初等对称和≤U_y^n/n!。因k/logL→∞，截断差是o(L^−3/2)=o(V(y))。上下夹逼即得(7.2)。

这个推导使用经典截断容斥和Mertens估计，不假设不同素数事件独立，也不需要新的指数和估计。

### 三种范围必须区分

- c≤0（2j≥r）：继承第七轮的精确空区，没有点。
- 固定c≥1、j→∞：有限条斜线的临界极限，通常不是面积主项；固定有限预筛还可能有周期密度。
- c增长且满足(7.1)：同一y=exp(√logm)预筛下恢复(7.2)。未筛计数只需c→∞即可，不要把未筛与预筛的条件混同。

本轮没有证明(7.1)最优，也没有完整处理固定c到这一范围之间所有可能的预筛过渡。

## 9. 文献范围与Main候选判断

本轮核对的一手研究/讲义：

1. I. E. Shparlinski, *Modular Hyperbolas*, arXiv:1103.2879v4。模逆元曲线的分布和几何已有成熟背景。https://arxiv.org/abs/1103.2879
2. J.-G. Dumas, *On Newton-Raphson iteration for multiplicative inverses modulo prime powers*, arXiv:1209.6626。逆元的p-adic展开/计算是经典结构；本轮不把有限逆元展开本身称为新工具。https://arxiv.org/abs/1209.6626
3. A. Bower, R. Evans, V. Luo, S. J. Miller, *Coordinate sum and difference sets of d-dimensional modular hyperbolas*, arXiv:1212.2930。说明模双曲线的和坐标已有直接先行研究；本轮只核对摘要和研究范围，未逐定理做优先权比对。https://arxiv.org/abs/1212.2930
4. K. S. Kedlaya, *Notes on analytic number theory*, Chapter12, Brun’s combinatorial sieve。截断容斥、主项和余项接口。https://kskedlaya.org/ant/chap-brun.html

本轮最完整的主结果候选是“精确临界斜线极限 + 永久符号不对称 + 近边界预筛主项”的统一结构，而不是声称已经获得孪生素数下界。

若以证明孪生素数为验收目标，本轮没有解决B_r的独立素数下界；也没有把平衡盒预筛点计数移植成整个污染区域的三素数主项。其价值是更准确地刻画 F₃ 几何何时遵循面积密度、何时必须使用离散斜线剖面，以及如何利用这一结构改善真实的整数筛分布。
