## 3. 关键审计点

### 3.1 四次检测必须看模 \(9\)

等层 \(a=b=m\) 时必须证明
\[
v_3(u_0^4+u_0^2v_0^2+v_0^4)=1.
\]
写 \(u_0^2=1+3r\)、\(v_0^2=1+3s\) 后，单位部分模 \(9\) 精确等于 \(3\)。

### 3.2 正部构造没有隐藏零极点

\[
\rho(x)=\frac{x(x^2+1)}{x^3-x+1}
\]
在 \(\mathbb Q^\times\) 上分子不为零；分母若有有理根只能是 \(\pm1\)，但两点函数值均为 \(1\)。

### 3.3 分类充分性允许负指数

\(a_-\) 和 \(c_r\) 可为负，因此中间对象是有理函数。最后统一写成 \(A/B\)，清系数分母并齐次化，才回到整数多项式对。

### 3.4 分类必要性对非齐次多项式成立

两条输入序列
\[
(3^m+1,3^m-1),\qquad(3^m+1,1-3^m)
\]
把任意固定非齐次 \(P\pm Q\) 变成关于 \(3^m\) 的固定一元多项式；最低非零次数项最终唯一控制赋值。

### 3.5 非齐次次数下界的降阶桥

共同缩放
\[
(n,d)\mapsto(3^mn,3^md)
\]
保持输入 \(F\) 不变。提取 \(P+Q,P-Q\) 的最低非零齐次部分后，两边最低次数必须相同；其比值在一般有理方向上已经实现相同 \(g\)。约分、利用同一三进环带的有理稠密性，得到次数不增加的一元既约有理函数实现。

### 3.6 四次下界的根论证

假定精确检测器次数 \(\le3\)，降阶得既约 \(A/B\)。

1. 有理逼近排除 \(A,B\) 的非零 \(\mathbb Q_3\) 根。
2. 正负尾都为 \(0\)，推出 \(A(0),B(0)\ne0\)、同次数、首项赋值相同、常数项赋值相同。
3. 次数 \(2\) 或 \(3\) 且无 \(\mathbb Q_3\) 根，故各自在 \(\mathbb Q_3[x]\) 中不可约。
4. 完备赋值域绝对值的唯一延拓使同一不可约多项式的共轭根具有相同赋值。
5. 韦达公式迫使 \(A,B\) 根半径相同；若非单位半径，单位环带上输出只能为 \(0\)，矛盾。
6. 因此根全为单位；归一化后 \(A,B\in\mathbb Z_3[x]\)，首尾系数为单位。
7. 单位层输出 \(1\) 强迫 \(A(\pm1)\equiv0\pmod3\)。
8. 次数 \(\le3\) 时两个不同根不可能同时重根，故至少一个简单根。
9. Hensel 提升产生非零 \(\mathbb Q_3\) 根，与第 1 步矛盾。

因此精确检测至少四次。
