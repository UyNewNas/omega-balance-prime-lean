## 3. 关键审计点

### 3.1 重复因子没有遗漏

低次数论证只使用
\[
P=\prod_i p_i^{e_i}\equiv n^{\sum e_i}\pmod{3^{k+s}},
\]
所以指数 \(e_i>1\) 完全允许。九变量总次数 \(1\) 到 \(8\) 的数量
\[
\binom{17}{8}-1=24309
\]
正确。

### 3.2 精度边界严格

若 \(u<3^s\)，则
\[
v_3(u)\le s-1,
\]
所以
\[
k+v_3(u)<k+s.
\]
在 \(u=3^s\) 时第一次取等号。

### 3.3 等距关系不是只靠导数

证明使用精确差分分解
\[
G_n(d)-G_n(e)
=
(d-e)(WCn^{q-1}+3^{k+s}K_n(d,e)),
\]
括号恒为三进单位，因此
\[
v_3(G_n(d)-G_n(e))=v_3(d-e)
\]
对全部 \(d,e\in\mathbb Z_3\) 成立。

### 3.4 奇异乘积正性

大素数局部因子
\[
\frac{\ell^{q-1}(\ell-q)}{(\ell-1)^q}
=
1+O_q(\ell^{-2}),
\]
所以偏离 \(1\) 的绝对值可求和。不是仅凭“每个因子正”断言无穷乘积正。

### 3.5 普通族与移动族的主系数确实相同

对 \(\ell\le q,\ell\ne3\)，\(W\) 使所有偏移都归零；对 \(\ell>q\)，两组系数都给出 \(q\) 个互异类。故每个素数处的局部因子逐项相同，而不仅是乘积碰巧相同。

## 4. 外部理论边界

Green–Tao 2010 明确说明复杂度至多 \(2\) 的情形无条件；一般固定 \(q\) 的系统复杂度有限，但可大于 \(2\)，因此使用后续完成的一般有限复杂度理论。这里没有把 2010 论文的一般条件性主定理误写成无条件。
