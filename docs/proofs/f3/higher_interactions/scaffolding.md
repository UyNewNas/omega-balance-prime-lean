## 4. 关键审计点

### 4.1 有符号方向没有混淆

当 (F_3(n)=k>0) 时，实际是
[
v_3(n+1)=k,qquad v_3(n-1)=0.
]
两两乘积则恰好反过来：
[
v_3(p_ip_j+1)=0,qquad v_3(p_ip_j-1)=k.
]
所以值是 (-k)，不是 (+k)。

### 4.2 三因子公式中的指数检查

[
rac{n^3+1}{3^{k+1}}
=
a-3^ka^2+3^{2k-1}a^3
]
在 (k=1) 时最后指数为 (1)，仍为整数且模 3 消失；不存在 (k=1) 边界缺口。

### 4.3 根提升的比例归一化

模 (3^T) 的单位类数是 (2cdot3^{T-1})。唯一根模 (3^t) 有 (3^{T-t}) 个提升，因此
[
Pr(v_3(G)ge t)=rac1{2cdot3^{t-1}}.
]
精确层 (tge1) 是相邻门槛相减：
[
3^{-t}.
]
加上 (t=0) 的 (1/2)，总和为
[
rac12+sum_{tge1}3^{-t}=1.
]

### 4.4 奇异级数不是“每项正所以乘积正”

对 (ellge5)
[
eta_ell
=
1-rac{3ell-1}{(ell-1)^3}
=
1+O(ell^{-2}),
]
因此偏离 1 的绝对值可求和，尾部乘积才严格非零。

### 4.5 固定剩余类的面积因子

原盒 (X<n,dle2X) 在固定模 (Q) 类内变成面积
[
X^2/Q^2+O(X)
]
的参数矩形，所以每类主项含 (Q^{-2})。汇总
[
4cdot3^{2A-k-2}
]
个类后得到精确常数
[
3^{2-k}mathfrak C.
]

### 4.6 精确深度所需模数

判定 (D=R) 需要确定
[
v_3(G)=R-k-1.
]
由于 (A(n)=(n^3+1)/3^{k+1})，取
[
Age R+1
]
即可保证参数模 (3^A) 信息覆盖所需余因子精度。

### 4.7 一般有限模式陈述已收紧

研究稿用“三进单位实现 (F_3)”作概念性表述。本证明包改成：先由普通正整数实现有限单项式模式，再取足够高的 (3^A) 保持所有精确赋值。这样不需要额外定义 (mathbb Z_3^	imes) 上的 (F_3)，也更适合 Lean。

## 5. 外部定理适用性

Green–Tao 2010 的出版页明确说明：系统无仿射相关、复杂度 (sle2) 的结论无条件成立，并特别覆盖四素数非退化配置。本主计数只使用这一层。

一般 F3-HI-3 使用任意有限个两两不平行形式，复杂度有限；其无条件版本依赖后续 Möbius–nilsequence 与 Gowers 逆定理的完成。这里引用外部定理，不在仓库中重证。
