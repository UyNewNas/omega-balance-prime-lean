## 1. 二次平移乘积

固定 \(k\ge1\)，令
\[
q=3^k.
\]
定义
\[
a_j=n+2jqd,\qquad
b_j=n+(2jq+2)d,
\]
以及
\[
Q_j=a_jb_j+1.
\]

直接展开：
\[
\begin{aligned}
Q_j
&=
(n+2jqd)(n+(2jq+2)d)+1\\
&=
4q^2d^2j^2+4qd(n+d)j+n(n+2d)+1.
\end{aligned}
\]
所以
\[
\boxed{
Q_j
=
4q^2d^2j^2+4qd(n+d)j+Q_0.
}
\tag{1.1}
\]

因此二阶差分恒为
\[
\boxed{
Q_{j+2}-2Q_{j+1}+Q_j=8q^2d^2.
}
\tag{1.2}
\]

特别地，
\[
Q_2-2Q_1+Q_0=8q^2d^2.
\tag{1.3}
\]

## 2. 基础高深度分支 \(E_k\)

定义
\[
E_k:
\qquad
d\equiv1\pmod3,\qquad
v_3(Q_0),v_3(Q_1)\ge2k+1.
\]

首先，\(Q_0\equiv0\pmod3\) 与 \(d\equiv1\pmod3\) 强迫
\[
n\equiv2\pmod3.
\tag{2.1}
\]
确实，
\[
Q_0=n(n+2d)+1
\]
模 \(3\) 下只有 \(n\equiv2\) 时为 \(0\)。

因为 \(q\equiv0\pmod3\)，对所有 \(j\)
\[
a_j\equiv n\equiv2\pmod3,
\]
\[
b_j\equiv n+2d\equiv1\pmod3.
\]
所以
\[
a_jb_j\equiv2\pmod3.
\]
于是
\[
v_3(a_jb_j-1)=0,
\]
并且
\[
\boxed{
D_j:=F_3(a_jb_j)=v_3(Q_j).
}
\tag{2.2}
\]

## 3. 第三组深度被锁定

由 \(E_k\)
\[
v_3(Q_0),v_3(Q_1)\ge2k+1.
\]
另一方面
\[
v_3(8q^2d^2)=2k
\]
因为 \(d\) 为三进单位。

由 (1.3)
\[
Q_2=(2Q_1-Q_0)+8q^2d^2.
\]
第一括号的赋值至少为 \(2k+1\)，第二项的赋值精确为 \(2k\)，两项赋值不同，所以和的赋值等于较小者：
\[
v_3(Q_2)=2k.
\]
由 (2.2)
\[
\boxed{D_2=2k.}
\tag{3.1}
\]

## 4. 归一化二次多项式

由 (1.1) 定义
\[
P(X)=\frac{Q_X}{4q^2d^2}
=
X^2+BX+C
\]
作为 \(\mathbb Z_3[X]\) 中的多项式，其中
\[
B=\frac{n+d}{qd},
\qquad
C=\frac{Q_0}{4q^2d^2}.
\tag{4.1}
\]

需要先说明 \(B,C\in\mathbb Z_3\)。

显然
\[
v_3(C)\ge1.
\tag{4.2}
\]

又
\[
Q_1-Q_0
=
4qd(n+d+qd).
\]
因为 \(Q_0,Q_1\) 都被 \(3^{2k+1}\) 整除，
\[
v_3(n+d+qd)\ge k+1.
\]
除以 \(qd\)：
\[
\frac{n+d}{qd}+1
=
\frac{n+d+qd}{qd}
\equiv0\pmod3.
\]
所以
\[
B\in\mathbb Z_3,\qquad B\equiv-1\pmod3.
\tag{4.3}
\]

结合 (4.2)：
\[
P(X)\equiv X^2-X=X(X-1)\pmod3.
\tag{4.4}
\]

因此模 \(3\) 有两个不同的简单根 \(0,1\)。

由 Hensel 简单根提升，存在唯一
\[
r_0\in3\mathbb Z_3,
\qquad
r_1\in1+3\mathbb Z_3
\]
使
\[
P(r_0)=P(r_1)=0.
\]
因为 \(P\) 是首一二次多项式，
\[
P(X)=(X-r_0)(X-r_1).
\]
乘回 \(4q^2d^2\)：
\[
\boxed{
Q_j
=
4q^2d^2(j-r_0)(j-r_1).
}
\tag{4.5}
\]

取赋值并利用 \(v_3(4q^2d^2)=2k\)：
\[
\boxed{
D_j
=
2k+v_3(j-r_0)+v_3(j-r_1).
}
\tag{4.6}
\]

## 5. 三条索引分支

写
\[
r_0=3Z_0,\qquad
r_1=1+3Z_1
\]
其中
\[
Z_0,Z_1\in\mathbb Z_3.
\]

### \(j=3u\)

有
\[
j-r_0=3(u-Z_0),
\]
而
\[
j-r_1\equiv-1\pmod3.
\]
所以
\[
\boxed{
D_{3u}=2k+1+v_3(u-Z_0).
}
\tag{5.1}
\]

### \(j=3u+1\)

有
\[
j-r_1=3(u-Z_1),
\]
而
\[
j-r_0\equiv1\pmod3.
\]
所以
\[
\boxed{
D_{3u+1}=2k+1+v_3(u-Z_1).
}
\tag{5.2}
\]

### \(j=3u+2\)

此时
\[
j-r_0\equiv2\pmod3,
\qquad
j-r_1\equiv1\pmod3,
\]
二者都是单位，因此
\[
\boxed{
D_{3u+2}=2k.
}
\tag{5.3}
\]

这解释了第三组为何一定锁定，以及为什么后续仍会在两个其他分支上不断出现更深层。

## 6. 由根恢复参数

设
\[
\sigma=r_0+r_1,
\qquad
\delta=r_1-r_0.
\]

由首一二次多项式
\[
P(X)=(X-r_0)(X-r_1)
=
X^2-\sigma X+r_0r_1,
\]
比较 \(X\) 系数和 (4.1)，得到
\[
\frac{n+d}{qd}=-\sigma.
\]
所以
\[
\boxed{
n=-d(1+q\sigma).
}
\tag{6.1}
\]

再看判别式。

由参数表达
\[
\Delta_P
=
B^2-4C
=
\frac{(n+d)^2-\bigl(n(n+2d)+1\bigr)}{q^2d^2}.
\]
分子化简为
\[
(n+d)^2-n(n+2d)-1
=
d^2-1.
\]
而根表达给出
\[
\Delta_P=(r_1-r_0)^2=\delta^2.
\]
因此
\[
\delta^2
=
\frac{d^2-1}{q^2d^2}.
\]
重排：
\[
1-q^2\delta^2=d^{-2}.
\]
所以
\[
\boxed{
d=(1-q^2\delta^2)^{-1/2}.
}
\tag{6.2}
\]

因为
\[
q^2\delta^2\equiv0\pmod3,
\]
括号属于 \(1+3\mathbb Z_3\)。平方根方程
\[
x^2=1-q^2\delta^2
\]
在 \(x\equiv1\pmod3\) 分支有唯一解；取其倒数，便得到唯一
\[
d\equiv1\pmod3.
\]

然后 (6.1) 唯一确定 \(n\)。

## 7. 任意两个根都给出唯一参数

反过来，任取
\[
r_0\in3\mathbb Z_3,
\qquad
r_1\in1+3\mathbb Z_3.
\]
定义
\[
\sigma=r_0+r_1,
\qquad
\delta=r_1-r_0.
\]
由 (6.2) 取唯一 \(d\equiv1\pmod3\)，再由 (6.1) 定义 \(n\)。

则
\[
B=\frac{n+d}{qd}=-\sigma.
\]
同时 (6.2) 保证参数多项式的判别式等于
\[
\delta^2.
\]
因此常数项必为
\[
\frac{\sigma^2-\delta^2}{4}
=
r_0r_1.
\]
所以
\[
P(X)=(X-r_0)(X-r_1).
\]

由于
\[
r_0\equiv0,\quad r_1\equiv1\pmod3,
\]
有
\[
P(0),P(1)\equiv0\pmod3.
\]
更精确地，
\[
v_3(Q_0)\ge2k+1,
\qquad
v_3(Q_1)\ge2k+1.
\]
所以构造出的 \((n,d)\) 属于 \(E_k\)。

于是得到双射
\[
\boxed{
E_k
\longleftrightarrow
3\mathbb Z_3\times(1+3\mathbb Z_3)
\longleftrightarrow
\mathbb Z_3^2,
}
\tag{7.1}
\]
其中最后一个坐标就是 \((Z_0,Z_1)\)。

## 8. Haar 测度与两个根的独立均匀性

写
\[
S=Z_0+Z_1,
\qquad
\Delta=Z_1-Z_0.
\]
则
\[
\sigma=1+3S,
\qquad
\delta=1+3\Delta.
\]

参数公式变成
\[
d=(1-q^2(1+3\Delta)^2)^{-1/2},
\]
\[
n=-d\bigl(1+q(1+3S)\bigr).
\]

\(d\) 只依赖于 \(\Delta\)。求导：
\[
\frac{\partial d}{\partial\Delta}
=
3q^2\delta d^3.
\]
所以
\[
v_3\left(\frac{\partial d}{\partial\Delta}\right)
=
2k+1.
\tag{8.1}
\]

又
\[
\frac{\partial n}{\partial S}
=
-3qd,
\]
故
\[
v_3\left(\frac{\partial n}{\partial S}\right)
=
k+1.
\tag{8.2}
\]

在 \((S,\Delta)\) 坐标下，
\[
\frac{\partial d}{\partial S}=0.
\]
所以 Jacobian 行列式为
\[
J
=
\frac{\partial n}{\partial S}
\frac{\partial d}{\partial\Delta},
\]
从而
\[
\boxed{
v_3(J)=3k+2.
}
\tag{8.3}
\]

而
\[
(Z_0,Z_1)\mapsto(S,\Delta)
\]
的行列式是 \(2\)，为三进单位。

因此这个解析双射在整个 \(\mathbb Z_3^2\) 上具有恒定 Jacobian 绝对值
\[
3^{-(3k+2)}.
\]
等价的有限剩余类陈述是：每个固定精度 \(T\) 下，每一对
\[
(Z_0\bmod3^T,Z_1\bmod3^T)
\]
对应 \(E_k\) 中同样数量的参数类。

故在 \(E_k\) 上归一化 Haar 测度后，
\[
\boxed{
Z_0,Z_1
\text{ 相互独立且各自为 }\mathbb Z_3\text{ 上均匀 Haar 变量}.
}
\tag{8.4}
\]

顺便得到
\[
\boxed{
\mu(E_k)=3^{-(3k+2)}
}
\tag{8.5}
\]
相对于 \(\mathbb Z_3^2\) 的标准 Haar 测度。

特别地，
\[
\mu(E_1)=3^{-5}.
\]

## 9. 完整联合尾分布

令
\[
L=2k+1.
\]

由 (5.1)，
\[
D_{3u}\ge L+t
\iff
v_3(u-Z_0)\ge t
\iff
Z_0\equiv u\pmod{3^t}.
\tag{9.1}
\]

同理
\[
D_{3u+1}\ge L+t
\iff
Z_1\equiv u\pmod{3^t}.
\tag{9.2}
\]

考虑有限组门槛
\[
D_{3u_i+c_i}\ge L+t_i,
\qquad
c_i\in\{0,1\}.
\]

在同一根分支中，所有条件都是对同一个 \(Z_c\) 的球条件
\[
Z_c\equiv u_i\pmod{3^{t_i}}.
\]
两个三进球的交集要么为空，要么等于半径更小的那个球。

因此同一分支条件相容当且仅当
\[
u_i\equiv u_j
\pmod{3^{\min(t_i,t_j)}}.
\tag{9.3}
\]
若相容，整组条件等价于唯一一个最深条件，概率为
\[
3^{-T_c},
\]
其中
\[
T_c=\max(\{t_i:c_i=c\}\cup\{0\}).
\]

两个根独立，所以
\[
\boxed{
\Pr(\text{全部门槛}\mid E_k)
=
3^{-(T_0+T_1)}
}
\tag{9.4}
\]
若两分支内部都相容；否则为 \(0\)。

例如：
\[
D_0\ge L+1
\iff
Z_0\equiv0\pmod3,
\]
\[
D_1\ge L+1
\iff
Z_1\equiv0\pmod3.
\]
故
\[
\Pr(D_0\ge L+1,D_1\ge L+1\mid E_k)
=
\frac19.
\]

而
\[
D_3\ge L+1
\iff
Z_0\equiv1\pmod3.
\]
因此
\[
\Pr(D_0\ge L+1,D_3\ge L+1\mid E_k)=0.
\]

这就是“不同根之间独立，同一根内部由三进球相容性控制”的完整联合律。

## 10. 完整 \(3^T\) 区段的层级数量

固定 \(1\le t\le T\)。

由 (4.6)，
\[
D_j\ge2k+t
\]
当且仅当
\[
j\equiv r_0
\quad\text{或}\quad
j\equiv r_1
\pmod{3^t}.
\]
因为
\[
r_0\not\equiv r_1\pmod3,
\]
两个类不相交。

任意连续 \(3^T\) 个整数中，每个模 \(3^t\) 剩余类恰出现
\[
3^{T-t}
\]
次。

所以
\[
\boxed{
\#\{j:D_j\ge2k+t\}
=
2\cdot3^{T-t}.
}
\tag{10.1}
\]

例如 \(T=2\) 时连续九项中：
- \(D_j=2k\) 恰有 \(3\) 项；
- \(D_j=2k+1\) 恰有 \(4\) 项；
- \(D_j\ge2k+2\) 恰有 \(2\) 项。

## 11. 完整深度序列恢复两个根

固定 \(T\ge1\)，看区间
\[
0\le j<3^T.
\]

由 (10.1) 对 \(t=T\)，恰有两个位置满足
\[
D_j\ge2k+T.
\]
它们分别是
\[
j\equiv r_0\pmod{3^T},
\qquad
j\equiv r_1\pmod{3^T}.
\]

由于一个模 \(3\) 为 \(0\)，另一个模 \(3\) 为 \(1\)，不会混淆。

让 \(T\) 逐步增加，就恢复
\[
r_0,r_1\in\mathbb Z_3
\]
的全部三进位。

再使用 (6.2)、(6.1)，恢复 \(d,n\)。

因此
\[
\boxed{
(D_j)_{j\ge0}
\text{ 在 }E_k\text{ 上唯一决定 }(n,d).
}
\tag{11.1}
\]

## 13. 自适应阈值查询

开始时已知
\[
r_0\equiv0,\qquad r_1\equiv1\pmod3.
\]

假设某个根已知模 \(3^t\)。它有三个模 \(3^{t+1}\) 的候选提升。

要判断某个候选 \(j\) 是否是真实提升，只需查询
\[
D_j\ge2k+t+1.
\]
若前两个候选都失败，第三个必然成功。

因此每一位每个根最多需要两个查询。

从精度 \(3\) 提升到 \(3^T\) 共 \(T-1\) 层，两个根总查询数至多
\[
\boxed{
4(T-1).
}
\tag{13.1}
\]

这里没有声称最优性。

## 14. 六个素数位置的模 \(5\) 障碍

现在取
\[
k=1,\qquad q=3.
\]
前三组位置是
\[
n,\ n+2d,\ n+6d,\ n+8d,\ n+12d,\ n+14d.
\]

系数集合
\[
\{0,2,6,8,12,14\}
\]
模 \(5\) 覆盖
\[
\{0,1,2,3,4\}.
\]

若
\[
5\nmid d,
\]
乘以 \(d\) 在模 \(5\) 上是置换，所以
\[
n+\{0,2,6,8,12,14\}d
\]
也覆盖所有模 \(5\) 剩余类。

因此其中至少一个被 \(5\) 整除。

若六个数都大于 \(5\) 且均为素数，这是不可能的。

故
\[
\boxed{
5\mid d.
}
\tag{14.1}
\]

而 \(E_1\) 要求
\[
d\equiv1\pmod3,
\]
所以 \(d\ne5\)。因此这里不能再要求 \(d\) 自身为素数。

## 15. 令 \(d=5r\) 后的七素数系统

设
\[
d=5r.
\]
七个需要为素数的形式是
\[
r,\quad
n,\quad
n+10r,\quad
n+30r,\quad
n+40r,\quad
n+60r,\quad
n+70r.
\tag{15.1}
\]

它们的齐次方向
\[
(0,1),
\quad
(1,0),(1,10),(1,30),(1,40),(1,60),(1,70)
\]
两两不同，所以系统有限复杂。

### 局部可容许性

- 模 \(2\)：取 \(n,r\) 都为奇数即可。
- 模 \(3\)：形式化简为
  \[
  r,\ n,\ n+r,\ n,\ n+r,\ n,\ n+r.
  \]
  合格单位类恰有
  \[
  (n,r)\equiv(1,1),(2,2)\pmod3.
  \]
  因此允许域比例为
  \[
  \frac29.
  \tag{15.2}
  \]
- 模 \(5\)：六个位置系数全部为 \(0\)，只需
  \[
  n,r\not\equiv0\pmod5.
  \]
- 对素数 \(\ell\ge7\)：固定 \(r\ne0\) 后，六个端点最多排除六个 \(n/r\) 类，而
  \[
  6<\ell.
  \]
  所以仍有允许类。

因此所有局部因子为正。除有限小素数外，局部因子为 \(1+O(\ell^{-2})\)，奇异乘积收敛到正数。

由一般有限复杂度素数线性形式定理，存在
\[
\mathfrak S>0
\]
使
\[
\boxed{
\#\mathcal P(X)
=
(\mathfrak S+o(1))
\frac{X^2}{(\log X)^7},
}
\tag{15.3}
\]
其中 \(\mathcal P(X)\) 是
\[
X<n,r\le2X
\]
且 (15.1) 全为素数的参数集合。

## 16. 模式 \((D_0,D_1,D_2)=(3,4,2)\) 的比例

在 \(k=1\) 时
\[
L=2k+1=3.
\]

第 8 节给出
\[
\mu(E_1)=3^{-5}.
\tag{16.1}
\]

在 \(E_1\) 内：
\[
D_0=3
\iff
v_3(Z_0)=0,
\]
其概率为
\[
\frac23.
\tag{16.2}
\]

同时
\[
D_1=4
\iff
v_3(Z_1)=1,
\]
其概率为
\[
\frac13-\frac19
=
\frac29.
\tag{16.3}
\]

两个根独立，所以
\[
\Pr(D_0=3,D_1=4\mid E_1)
=
\frac23\cdot\frac29
=
\frac4{27}.
\tag{16.4}
\]

而
\[
D_2=2
\]
在 \(E_1\) 上自动成立。

因此这个精确事件与 $d\equiv1\pmod3$ 分支的交集在 \((n,d)\in\mathbb Z_3^2\) 中的 Haar 测度是
\[
3^{-5}\cdot\frac4{27}
=
\frac4{3^8}.
\tag{16.5}
\]

全族还包含 $d\equiv2\pmod3$ 分支。对所有 $j$，
\[
Q_j(-n,-d)=Q_j(n,d).
\]
同时取负是模 $3^A$ 参数类上的保测度双射，交换两个非零 $d$ 分支，保持全部精确深度及允许素数剩余类。因此另一分支贡献同样的 $4/3^8$，完整事件的 Haar 测度是 $8/3^8$。$d\equiv0\pmod3$ 时 $Q_0\equiv n^2+1\not\equiv0\pmod3$，不贡献事件。这里使用的是有限剩余类的双射，不把正参数的素数映成负素数。

把 \(d=5r\) 看成三进单位线性变换，不改变测度。

另一方面，七素数系统在模 \(3\) 的全部允许参数域比例为 (15.2)
\[
\frac29.
\]

对每个固定高三进参数类，所有 \(\ell\ne3\) 的局部素数因子完全相同；模 \(3\) 内每个允许类也有相同归一化权。

因此有限复杂度素数计数逐类求和后，精确模式在全七素数族中的渐近比例就是
\[
\frac{8/3^8}{2/9}
=
\boxed{\frac4{729}}.
\tag{16.6}
\]

于是
\[
\boxed{
\#\{(n,r)\in\mathcal P(X):(D_0,D_1,D_2)=(3,4,2)\}
=
\left(
\frac4{729}\mathfrak S+o(1)
\right)
\frac{X^2}{(\log X)^7}.
}
\tag{16.7}
\]

主系数严格为正，所以这种七素数模式出现无穷多次。

## 18. 文献边界

本文双根分解本质上是一个二次多项式在 \(\mathbb Z_3\) 上的两个简单 Hensel 根。二次多项式 \(p\)-进赋值树、尤其平方判别式导致两个无限分支的一般结构已有系统分类，因此本文不声称“双分支”这一抽象现象本身新颖。

随机 \(p\)-进多项式根的分布、矩与相关性也已有独立文献。本文登记的是：

1. 这个特定 \(F_3\) 平移乘积过程的显式参数化；
2. 根坐标下完整的有限联合尾律；
3. 深度序列到参数的显式可逆重建与有限精度查询界；
4. 扩展到全素数配置时出现的模 \(5\) 强制尺度障碍及其修复。

全素数无穷性仍是既有有限复杂度素数线性形式理论的应用，不是新的素数分布定理。
