## 3. 关键审计点

### 3.1 \(P(X)\) 的线性系数确实是三进整数

由
\[
Q_1-Q_0=4qd(n+d+qd)
\]
和 \(v_3(Q_0),v_3(Q_1)\ge2k+1\) 得
\[
v_3(n+d+qd)\ge k+1.
\]
所以
\[
B=\frac{n+d}{qd}\equiv-1\pmod3.
\]

### 3.2 反演式重新推导

判别式满足
\[
(r_1-r_0)^2
=
\frac{(n+d)^2-(n(n+2d)+1)}{q^2d^2}
=
\frac{d^2-1}{q^2d^2}.
\]
因此
\[
d=(1-q^2(r_1-r_0)^2)^{-1/2}.
\]
没有漏掉符号分支：\(d\equiv1\pmod3\) 唯一选定平方根。

### 3.3 Haar 独立性不是从前两个输出猜出来的

令
\[
S=Z_0+Z_1,\qquad \Delta=Z_1-Z_0.
\]
有
\[
v_3(\partial n/\partial S)=k+1,\qquad
v_3(\partial d/\partial\Delta)=2k+1,
\]
且交叉坐标变换行列式 \(2\) 为单位，因此总 Jacobian 赋值恒为
\[
3k+2.
\]
这给出有限剩余类等量性与条件乘积 Haar 测度。

### 3.4 \(2/729\) 的归一化口径

\(k=1\) 时
\[
\mu(E_1)=3^{-5}.
\]
条件于 \(E_1\)，
\[
\Pr(D_0=3)=2/3,\qquad
\Pr(D_1=4)=2/9,
\]
且独立，所以精确事件的绝对 Haar 测度为
\[
3^{-5}\cdot4/27=4/3^8.
\]
七素数系统模 \(3\) 的全部允许域是两个类，占 \(2/9\)。故条件比例
\[
(4/3^8)/(2/9)=2/729.
\]

### 3.5 模 \(5\) 障碍是强制的

系数 \(\{0,2,6,8,12,14\}\) 模 \(5\) 覆盖全部五类。若 \(5\nmid d\)，乘以 \(d\) 仍覆盖全部类，所以六位置中必有一个被 \(5\) 整除。

## 4. 文献边界
