PAT-L1–L3 是独立的局部算术部分，对所有满足前提的整数成立。PAT-L6 承担无限范围的素数存在性，不能用实验或 PAT-L3 替代。证明没有从一个等差数列中有无穷多个素数，跳到多个形式同时为素数。

## 3. 外部定理适用检查

本次使用固定的 `arXiv:math/0606088v2`，不依赖可变的最新版本编号。

| 检查项 | 本构造中的核对 |
|---|---|
| 原文是否有未证前提 | 一般 Main Theorem 在原文中有条件；本次只用无条件 Corollary 1.7 |
| 系统复杂度 | 对每个形式把其余三个分别分组；非平行性排除仿射依赖，故至多 2 |
| 参数、形式数 | 两个参数、四个固定形式；不固定 $v$ 或 $d$ |
| 系数尺寸 | 全部系数固定，允许取一个很大的固定尺寸常数 |
| 区域 | $K_X=[X,2X]^2$，取原定理尺度 $N=2X$，凸且面积为 $X^2$ |
| 正值和对数尺度 | $729X\le L_i\le215000X$，故四个 $\log L_i\sim\log X$ |
| 素数 3 | 形式固定为 $(2,1,1,1)\pmod3$ |
| 其他每个素数 | $u=-4\cdot729^{-1},v=-729^{-1}\pmod\ell$ 使全部形式等于 1 |
| 奇异乘积 | 每项正，且大素数尾部为 $1+O(\ell^{-2})$，故乘积不为零 |
| 素数与素数幂 | 使用素数计数式 (1.8)，不把 von Mangoldt 支持集全部当成素数 |
| 量词 | 对任意 $B$，足够大的方框给出 $n,d>B$；不推出固定尺度的无穷性 |

原文定位及正式出版信息见 [proof.md](proof.md#参考文献)。本轮核对的是引用的陈述及其应用，不是独立重证 Green–Tao 的整篇论文。

## 5. 书面审计记录（2026-09-29）

审计对象为既有证明提交 `eb9461251ffad65ab130088c3e5fba2917260b20` 中的四文件证明包。本轮由 Codex 对该提交逐项复核，并与固定版本 [GT10] 的原文核对；这是对既有稿件的书面数学审计，不冒称外部人工审稿，也不重证所引用的深定理。

- **定义与边界：通过。** 所有赋值的输入为正整数，所有差分在整数中解释；$n\ge2,d\ge1$ 保证邻数非零及四数严格递增。
- **PAT-L1–L3：通过。** 同余稳定性有一般证明；单点赋值为 $(1,-1,-1,-1)$，乘积加一代表元为 $(216,486,756)$，精确赋值依次为 $3,5,3$，各项均小于 6，乘积减一均不被 3 整除。
- **PAT-L4：通过。** 六个方向行列式非零，三组单元素覆盖满足 Definition 1.5，复杂度至多 2。
- **PAT-L5：通过。** 素数 3 与其他素数均有全体形式非零的局部解；大素数因子精确计数给出可求和尾部，足以保证整个奇异乘积严格为正。
- **EXT-GT2、PAT-L6：通过。** 对照 arXiv:math/0606088v2 的 Definition 1.5、Corollary 1.7、式 (1.8) 与其归约说明；固定尺寸、凸区域、正值、面积及素数而非素数幂的计数均满足引用要求。
- **PAT-L7：通过。** 参数映射单射，正计数在任意充分大的方框内成立，故两个参数可同时超过任意给定下界；不存在交换固定步长量词的步骤。

审计未发现影响数学结论的缺口。本轮补明同余条件只负责赋值、实数处因子为 $X^2$，以及与固定步长 Dickson 型问题的区别。依据 README 的状态定义，将 F3-PAT-1 从 `PAPER-PROVED` 更新为 `PAPER-AUDITED`；主结果仍未形式化。
