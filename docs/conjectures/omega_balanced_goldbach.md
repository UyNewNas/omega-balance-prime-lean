# Ω 平衡奇素数的二元加法覆盖猜想

登记日期：2026-09-24。来源：本项目讨论及同日完成的一亿以内验算。

**状态：本仓库尚未证明，也未将这些猜想转成已证明的 Lean theorem。** 本档案不声明文献首创，不把有限计算、猜想陈述或条件性推论当作形式化证明；不新增自定义公理或证明占位。

## 1. 定义与量词

令 Ω(n) 为正整数 n 的质因数总个数，重复的质因数计入重数。定义

$$
\mathcal B=\{p\in\mathbb N:p>2,\ p\text{ 为素数},\ \Omega(p-1)=\Omega(p+1)\}.
$$

这与现有 Lean 谓词 `IsOmegaBalancedPrime` 配合 `p > 2` 一致。它**不是**质因数计重求和函数 S 的平衡，也不是要求 F₃ 为零。

默认允许 p=q。每个加数各自左右平衡即可，不要求两个加数具有相同的共同 Ω 值。记

$$
R_{\mathcal B}(E)=\#\{(p,q):p,q\in\mathcal B,\ p\le q,\ p+q=E\}.
$$

目标是判断 R_B(E)>0，而不是给出每个 E 的全部分解或分解数渐近式。

<a id="obg-1"></a>
## 2. OBG-1：充分大偶数覆盖

$$
\exists N_0\in\mathbb N,\quad
\forall N\in\mathbb N,\ N\ge N_0\Longrightarrow
\exists p,q\in\mathcal B,\quad 2N=p+q.
$$

即所有充分大的偶数都是两个 Ω 平衡奇素数之和。没有指定阈值，也没有声称例外集已经被证明有限。

<a id="obg-2"></a>
## 3. OBG-2：显式起点版

$$
\forall N\in\mathbb N,\ N\ge259\,299\Longrightarrow
\exists p,q\in\mathcal B,\quad 2N=p+q.
$$

等价表述：每个偶数 E≥518598 都满足 R_B(E)>0。

目前逐项验证的范围是 518598≤E≤100000000，亦即 259299≤N≤50000000。518596 是已经找到且复核过的不可表示偶数，因此 518598 是此显式猜想提出的最小偶数起点；**尚未证明一亿以外不再出现更大的例外**。

<a id="obg-3"></a>
## 4. OBG-3：不同加数加强版

$$
\forall N\in\mathbb N,\ N\ge259\,299\Longrightarrow
\exists p,q\in\mathcal B,\quad p<q\ \land\ 2N=p+q.
$$

这是 OBG-2 的候选加强版，不是从 OBG-2 已经推出来的定理。同一有限区间内它仍成立。

逻辑关系为

$$
\mathrm{OBG\text{-}3}\Longrightarrow\mathrm{OBG\text{-}2}\Longrightarrow\mathrm{OBG\text{-}1}.
$$

若 OBG-1 成立，则 B 必为无限集：有限集的二元和集仍有限，不可能包含全部充分大偶数。这只是猜想的条件性后果，不是本仓库已经证明了 B 的无穷性。由于 B 是素数集合的子集，这些猜想也比相应范围内不附加平衡要求的素数和存在性更强。

## 5. 已否定的原始版本

“两个 Ω 平衡奇素数之和覆盖全体正偶数”是假的，甚至将目标限制到偶数 E≥4 或 E≥10 也不成立。

一个可手算反例是 E=100。百以内的平衡奇素数恰为

$$
5,\ 19,\ 29,\ 43,\ 67,\ 89.
$$

若 p+q=100，交换后取 p≤q，则 p≤50，只需检查 p=5,19,29,43。对应 q=95,81,71,57；前三个合数候选 95、81、57 不可用，而 71 虽为素数，却满足

$$
70=2\cdot5\cdot7,\qquad72=2^3\cdot3^2,
\qquad\Omega(70)=3\ne5=\Omega(72).
$$

因此 100 不能表示。这个手算/计算反例记录在本档案中，尚未作为新的 Lean 回归 theorem 加入；不要混入 README 的“已形式化实例与反例”表。

## 6. 一亿以内的有限证据

[原扫描汇总](../../data/omega_goldbach/run_1e8_summary.json)固定了以下计数。每个目标均检查，而非随机抽样；筛到 X+1 以覆盖右邻数。

| 上界 X | 不超过 X 的平衡奇素数 | [2,X] 内不可表示偶数 | 该范围的最大例外 |
|---:|---:|---:|---:|
| 100 | 6 | 39 | 100 |
| 1000 | 29 | 310 | 1000 |
| 10000 | 169 | 1733 | 10000 |
| 100000 | 1335 | 3003 | 99824 |
| 1000000 | 10300 | 3088 | 518596 |
| 10000000 | 84283 | 3088 | 518596 |
| 100000000 | 717650 | 3088 | 518596 |

在 [2,100000000] 的 50000000 个偶数中，49996912 个可表示，3088 个不可表示。禁止 p=q 只新增24个小例外，最大的新增例外为10102；这24项保存在汇总的 `extra_missing_if_distinct_required` 字段。因此在 518598 至一亿间，不同加数版仍逐项成立。

最后十个允许重复加数时的例外为

```text
250424, 252316, 266176, 267556, 306916,
316576, 324052, 345136, 373064, 518596
```

实际分解例如 518598=1667+516931、1000000=5333+994667、100000000=7253+99992747；加数均各自满足 Ω 平衡。最后一对的平衡级数分别为5、4，说明本猜想没有同级要求。

有限范围内没有遗漏不提供更大范围的下界证明，也不能推出无穷多个解或唯一的最终阈值。

本次入库重新执行了三种检查至 10^6：主扫描、独立 C++ 筛与全部见证/负例复核、Python 整数位集和集计算。重新得到10300个平衡奇素数、3088个例外、最大例外518596；完整例外数值及24个不同加数附加例外均与原归档逐项一致。**本次没有重新执行 10^8 扫描；该范围的证据来自上述原始归档。**

算法边界：主程序对每个偶数按升序搜索 p≤E/2，找到实际 q=E-p 才标记可表示；否则完整耗尽所有候选。独立程序另用 Eratosthenes 判素，并对所有素数幂的倍数累加 Ω，不复用主程序的最小素因子递推。它验证全部正见证并重新穷举所有负例；对只有对角见证 p=q 的情况，也检查没有更小的不同加数见证。第三种算法以任意精度整数位移和按位或直接计算 B+B，不用浮点 FFT。

**三种检查均为整数程序计算，不是 Lean 内核验证。原有 Lean 定理、工具链、公理审计及工作流不因本猜想登记而改变。**

## 8. 复现

原始源文件逐字保留在 [scripts/omega_goldbach](../../scripts/omega_goldbach)。需要 C++17 编译器；可选的第三种检查需要 Python 与 numpy，且禁止使用 `python -O`。其固定检查上界为10^6，输入的主扫描上界不得小于10^6。

从仓库根目录执行以下 Bash 命令；大文件保存在临时目录而非仓库中：

```bash
set -e
work="$(mktemp -d)"
g++ -O3 -std=c++17 scripts/omega_goldbach/check_omega_goldbach.cpp -o "$work/scan"
g++ -O3 -std=c++17 scripts/omega_goldbach/verify_witnesses_independent.cpp -o "$work/audit"
"$work/scan" 100000000 "$work/run_1e8"
"$work/audit" 100000000 "$work/run_1e8"
python3 scripts/omega_goldbach/independent_verify.py --prefix "$work/run_1e8"
diff -u data/omega_goldbach/run_1e8_summary.json "$work/run_1e8_summary.json"
sha256sum "$work/run_1e8_missing.txt"
```

完整例外文件的期望 SHA-256（包括首行注释和末尾换行）为：

```text
b0b49e61fb41492832c0a3d621e3ce718a6b8b0ea2877c6c50f0a023e607aee6
```

百万范围回归可将两个 C++ 调用的上界都改为1000000；这时不要直接比较一亿的汇总文件或带上界注释的例外文件哈希。

完整平衡素数清单、3088项例外清单及约200MB的见证文件均可重建，本次不将这些生成输出提交到仓库。见证以本机字节序的32位无符号整数保存，0表示不可表示；跨不同字节序机器时应在目标机器重新生成，或显式转换。主筛一亿上界约需600MB基础数组，另有素数列表与其他开销；两份 C++ 程序顺序运行。
